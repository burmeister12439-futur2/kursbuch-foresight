# Kursbuch Foresight

**Arbeitsstand · 28. August 2026**

Das Kursbuch Foresight ist ein offener Atlas eines Feldes im Wandel.

Es untersucht:
- wie sich Begriffe, Praktiken und Akteure unterscheiden,
- wo das Feld heute steht,
- welche Fragen sich für seine Zukunft stellen.

Dieser öffentliche Stand dient zunächst der Diskussion im Kernteam.
